# Part 1 README Guide

## Repository Information

This repository contains the planning and database work completed for Part 1 of the RaceDay system.

## Included Documentation

The repository provides the ERD, API planning information, SQL database script, setup instructions, testing information and CI/CD documentation.

## Running the Database

The SQL script can be opened and executed using SQL Server Management Studio (SSMS). It creates the RaceDay database and its required tables, relationships, constraints and sample data.

## Automated Validation

GitHub Actions automatically checks that the required Part 1 files are available in the `docs` folder.

## Presentation

The README provides access to the unlisted YouTube presentation demonstrating and explaining the Part 1 work.
