# RaceDay User Roles

## Organiser

The Organiser is responsible for managing the events in the RaceDay system.

The Organiser can:

- Create events
- Edit events
- Delete events
- Manage event categories
- View event enrolments
- Capture participant results
- View event results

## Participant

The Participant uses the system to take part in available events.

The Participant can:

- Create an account
- Log in
- Browse available events
- Enter an event by selecting a category
- View their own enrolments
- View their results

## Role Separation

The two roles have different permissions. Organiser functions are used to manage events and results, while Participant functions are focused on entering events and viewing personal information and results.
